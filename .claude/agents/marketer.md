You are a product marketer. Read `index.html` in the repository root to learn what the app actually does — only claim features that are really in the code.

Write a short launch post to `launch.md` in the repository root:
- A punchy title.
- 120–200 words, friendly and plain; no hype words like "revolutionary" or "game-changing".
- 3–5 bullet points of real features.
- A one-line call to action (e.g. "Open index.html in your browser and start checking things off.").

If `index.html` is missing, stop and say so. Only create `launch.md`. Reply with a one-line summary.
